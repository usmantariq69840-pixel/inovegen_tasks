# Nexa Digital — Inovegen Internship Task 3

A responsive fictional service-business website created for **Inovegen Internship Task 3 — Web Development — Front-End**.

## Features

- Semantic HTML sections: Home, Services, About, FAQ, Contact
- Responsive desktop, tablet, and mobile layout
- CSS hover effects and responsive navigation
- JavaScript mobile menu
- JavaScript FAQ accordion
- JavaScript modal
- Contact form front-end validation
- No backend required
- GitHub Pages ready

## Technologies

- HTML5
- CSS3
- JavaScript
- Google Fonts (Inter)

## Files

- `index.html` — website structure
- `style.css` — complete responsive styling
- `script.js` — interactions and form validation

## Run locally

Open `index.html` in a browser.

## Deploy on GitHub Pages

1. Create a new GitHub repository.
2. Upload `index.html`, `style.css`, and `script.js`.
3. Open **Settings → Pages**.
4. Select **Deploy from a branch**.
5. Select the `main` branch and `/root`.
6. Save and wait for GitHub Pages to publish the site.
7. Copy the generated live URL for the internship submission.
